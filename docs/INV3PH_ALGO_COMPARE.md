## 1. 算法原理概述

### 1.1 三相正负序分离 DQ 控制

三相 DQ 控制基于 Clarke 变换（abc → αβ）和 Park 变换（αβ → dq），将三相交流量映射为静止或旋转坐标系下的直流量，在同步旋转坐标系中用 PI 控制器实现无静差控制。

当电网不平衡时，αβ 平面中的电压/电流矢量不再做匀速圆周运动，而是做椭圆运动，此时须引入**正负序分离**，将信号分解为以 $+\omega$ 旋转的正序分量和以 $-\omega$ 旋转的负序分量，分别建立独立的 dq 控制环。

**信号分解原理（以 DSOGI 为例）：**

$$
\begin{bmatrix} v_\alpha^+ \\ v_\beta^+ \end{bmatrix}
= \frac{1}{2}
\begin{bmatrix} 1 & -q \\ q & 1 \end{bmatrix}
\begin{bmatrix} v_\alpha \\ v_\beta \end{bmatrix}
\quad
\begin{bmatrix} v_\alpha^- \\ v_\beta^- \end{bmatrix}
= \frac{1}{2}
\begin{bmatrix} 1 & q \\ -q & 1 \end{bmatrix}
\begin{bmatrix} v_\alpha \\ v_\beta \end{bmatrix}
$$

其中 $q$ 表示 90° 移相算子，由二阶广义积分器（SOGI）实现。

**控制拓扑（双 dq 框架）：**

```
                ┌─────────────────────────────────────┐
abc 采样 ─→ Clarke ─→ DSOGI/DDSRF ─→ 正序 dq+ ─→ PI ─┐
                                  └→ 负序 dq- ─→ PI ─┤
                                                      ↓
                                              矢量叠加 → SVPWM → 逆变器
                └─────────────────────────────────────┘
```

### 1.2 三个独立单相控制

将三相逆变器视为三个共用直流母线的单相逆变器，每相独立完成：采样 → 锁相 → 电压/电流控制 → PWM 调制。

每相通常采用：

- **PR（比例谐振）控制器**：直接在静止坐标系中对正弦量进行无静差跟踪
- **单相 Park 变换**：利用虚拟正交信号构造单相 dq 系统（SOGI-QSG）
- **重复控制（Repetitive Control）**：配合基波 PR 使用，抑制周期性谐波

**控制拓扑（三通道并行）：**

```
A 相采样 ─→ PLL_A ─→ PR/单相DQ ─→ PWM_A ─┐
B 相采样 ─→ PLL_B ─→ PR/单相DQ ─→ PWM_B ─┤─→ 逆变器
C 相采样 ─→ PLL_C ─→ PR/单相DQ ─→ PWM_C ─┘
```

## 2. 坐标变换与控制结构

| 项目       | 三相 DQ（含正负序分离）                                                             | 三个独立单相                          |
| ---------- | ----------------------------------------------------------------------------------- | ------------------------------------- |
| 坐标变换   | Clarke + Park（正负序各一套）                                                       | 每相 SOGI-QSG 或直接 PR，无需三相变换 |
| 被控量性质 | 旋转坐标系直流量$i_d$、$i_q$        | 静止坐标系正弦量$i_a$、$i_b$、$i_c$ |                                       |
| 控制器类型 | PI（稳态零误差）                                                                    | PR / 滞环 / 单相dq-PI                 |
| 解耦需求   | 需要前馈解耦（$\omega L$ 交叉耦合项）                                             | 各相自然解耦，无相间耦合              |
| 零序处理   | DQ 框架天然不含零序，须额外处理                                                     | 可独立控制零序，但需注意硬件拓扑支持  |
| 状态变量数 | 正序$d^+q^+$ + 负序 $d^-q^-$ = 4 个                                             | 每相 2 个，共 6 个                    |

## 3. 锁相环设计

### 3.1 三相 DQ 方案

采用**三相 SRF-PLL** 或 **DSOGI-PLL**，在电网平衡时性能优异，锁相精度高、抗干扰强。不平衡时须配合 DSOGI 或 DDSRF 提取正序分量再锁相，否则锁相角中会含有 2 倍频纹波，导致控制量脉动。

**优点：**

- 一个 PLL 覆盖全局，参数统一管理
- 正序锁相与正序控制天然匹配

**缺点：**

- 不平衡时 PLL 设计复杂，需抑制 2 次谐波
- 电网严重波动时正序提取有延迟

### 3.2 三个独立单相方案

每相配置独立 **单相 PLL（SOGI-PLL）**，三个 PLL 并行运行，互不依赖。

**优点：**

- 每相锁相不受其他相干扰
- 可独立应对各相电压畸变、相位偏移
- 单相 SOGI-PLL 结构成熟，调参简单

**缺点：**

- 三路 PLL 算量是三倍，且需协调输出相位（并网时对称性要求）
- 三路 PLL 的参数一致性影响三相对称性

## 4. FPGA 资源占用

这是两者在 FPGA 上落地时最显著的差异之一。

### 4.1 逻辑资源对比（控制周期内运算量 / 例化规模）

| 资源                           | 三相 DQ（正负序）                                                                    | 三个独立单相                     |
| ------------------------------ | ------------------------------------------------------------------------------------ | -------------------------------- |
| 坐标变换乘法次数（每控制周期） | ~24（Clarke + Park ×2 + 反变换）                                                    | ~18（3×SOGI QSG，每相2次乘加）  |
| PI/PR 控制器实例数             | 4（$i_{d+}$、$i_{q+}$、$i_{d-}$、$i_{q-}$）                                  | 6（每相电流 + 每相电压，如双环） |
| PLL 实例数                     | 1（DSOGI-PLL）                                                                       | 3（每相独立 PLL）                |
| DSOGI/SOGI 模块数              | 2（$v_\alpha$、$v_\beta$）                      | 3（$v_a$、$v_b$、$v_c$） |                                  |
| **DSP48 / 乘法器估算**   | 较少（共享变换与环路）                                                               | 较多（三通道并行例化）           |
| **寄存器 / BRAM 状态**   | 较少（dq 维数压缩）                                                                  | 较多（三套环路状态）             |
| **逻辑相对占用**         | **基准 100%**                                                                  | **约 130%～150%**          |

> **结论：三相 DQ 方案在 FPGA 上逻辑/DSP 占用约节省 25%～35%，适合 LUT/DSP 预算紧的设计。**

### 4.2 资源占用原因分析

三相 DQ 方案之所以更省资源，根本原因是**三相对称系统的能量守恒性**：在平衡条件下，三相电流在 dq 坐标系中只剩两个独立变量（$i_d$、$i_q$），相当于用 2 维来控制 3 维，降维带来了运算与例化规模的减少。

三个单相方案则不做此假设，保留了全部 3 个维度的控制自由度，付出了更多 FPGA 资源换取更强的控制灵活性。

## 5. 并网功率控制精度

### 5.1 三相 DQ 方案

**平衡电网（理想情况）：**

dq 分量与有功/无功功率直接对应：

$$
P = \frac{3}{2}(v_{d+} i_{d+} + v_{q+} i_{q+}), \quad Q = \frac{3}{2}(v_{q+} i_{d+} - v_{d+} i_{q+})
$$

控制 $i_{d+}$ 调有功，控制 $i_{q+}$ 调无功，直观且高效。

**不平衡电网（含负序分量）：**

若只控制正序 dq，则输出功率中会含有 2 倍频波动：

$$
P(t) = P_0 + P_{c2}\cos(2\omega t) + P_{s2}\sin(2\omega t)
$$

此时**无法单独精确控制某一相的注入功率**，只能通过正负序协调控制来约束功率脉动（例如选择"消除功率双频脉动"或"消除电流负序"两种目标之一，鱼和熊掌不可兼得的问题）。

> **关键劣势：在不平衡并网场景下，无法实现逐相功率精确独立控制。**

### 5.3 专题分析：通过注入负序电流实现逐相有功功率控制

这是一个关键问题：**能否在三相 DQ 框架内，利用负序电流的注入来实现对每一相平均有功功率的独立控制，从而达到与三个单相方案相同的效果？**

**答案是：理论上完全可行，但存在重要限制条件。**

#### 5.3.1 数学推导

设电网电压为理想平衡正序（以 A 相为参考）：

$$
v_a = V\cos(\omega t),\quad v_b = V\cos\!\left(\omega t - \frac{2\pi}{3}\right),\quad v_c = V\cos\!\left(\omega t + \frac{2\pi}{3}\right)
$$

同时注入正序电流（幅值 $I^+$，相位角 $\phi^+$）和负序电流（幅值 $I^-$，相位角 $\phi^-$）：

$$
i_a = I^+\cos(\omega t - \phi^+) + I^-\cos(\omega t - \phi^-)
$$

对三相分别计算一个基波周期内的平均有功功率（利用积化和差，仅直流项贡献平均值）：

$$
\boxed{P_a = \frac{VI^+}{2}\cos\phi^+ + \frac{VI^-}{2}\cos\phi^-}
$$

$$
\boxed{P_b = \frac{VI^+}{2}\cos\phi^+ + \frac{VI^-}{2}\cos\!\left(\phi^- - \frac{4\pi}{3}\right)}
$$

$$
\boxed{P_c = \frac{VI^+}{2}\cos\phi^+ + \frac{VI^-}{2}\cos\!\left(\phi^- + \frac{4\pi}{3}\right)}
$$

注意负序项之和恒为零：

$$
\cos\phi^- + \cos\!\left(\phi^- - \frac{4\pi}{3}\right) + \cos\!\left(\phi^- + \frac{4\pi}{3}\right) = 0
$$

因此 $P_a + P_b + P_c = \frac{3VI^+}{2}\cos\phi^+$，总有功功率**仅由正序决定**，负序电流只负责在各相之间重新分配功率，不影响总量。

#### 5.3.2 逆向求解：由目标功率确定所需负序电流

给定目标 $P_a^*, P_b^*, P_c^*$（满足 $P_a^*+P_b^*+P_c^*=P_{total}^*$），求解步骤：

**Step 1**：由总功率确定正序有功分量：

$$
I^+\cos\phi^+ = \frac{2P_{total}^*}{3V}
$$

**Step 2**：定义每相偏差（与均等分配的差值）：

$$
\Delta P_k = P_k^* - \frac{P_{total}^*}{3}, \quad k \in \{a,b,c\}，\text{且 } \Delta P_a + \Delta P_b + \Delta P_c = 0
$$

**Step 3**：将偏差投影到两个正交轴求解负序电流的实虚分量：

$$
X = \frac{VI^-}{2}\cos\phi^- = \Delta P_a
$$

$$
Y = \frac{VI^-}{2}\sin\phi^- = \frac{\Delta P_c - \Delta P_b}{\sqrt{3}}
$$

**Step 4**：转换为负序 dq 参考值。

负序 dq 坐标系以 $\theta_- = -\theta_+$（即对正序 PLL 角取负）为旋转角，对负序电流 $i_a^- = I^-\cos(\omega t - \phi^-)$ 施加负序 Park 变换，可得：

$$
i_{d-} = I^-\cos\phi^-, \quad i_{q-} = I^-\sin\phi^-
$$

将此代入 Step 3 的 $X = \tfrac{V}{2}I^-\cos\phi^-$、$Y = \tfrac{V}{2}I^-\sin\phi^-$，即得**直接可送入负序 dq 控制环的电流参考值**：

$$
\boxed{i_{d-}^* = \frac{2\Delta P_a}{V}}
$$

$$
\boxed{i_{q-}^* = \frac{2\left(\Delta P_c^* - \Delta P_b^*\right)}{\sqrt{3}\,V}}
$$

其中 $V$ 为正序相电压峰值（若采用 RMS 值则将分子系数 $2$ 替换为 $\sqrt{2}$）。

> **关于 $i_{d-}^*$ 为负值的说明：**
>
> $i_{d-}^*$ 出现负值是**完全正常的物理状态，不是控制错误**。当 A 相目标功率低于三相平均值时（$P_a^* < P_{total}^*/3$），$\Delta P_a < 0$，从而 $i_{d-}^* < 0$。其物理含义是负序电流相量的相角满足 $\cos\phi^- < 0$（即 $\phi^- \in (90°,\,270°)$），此时负序电流对 A 相的贡献为负有功——这正是将功率从 A 相向 B/C 相转移所需的方向。
>
> 负序 dq 控制环的 PI 控制器对正负两个方向的参考值均可无静差跟踪，与正序环中 $i_{d+}^*$ 可为负（逆变器工作于整流/吸收模式）的原理完全相同。只需确保实现中**没有将 $i_{d-}^*$ 取绝对值或单向限幅**，符号信息就会被 Park 逆变换正确还原为电流波形。

**验证——前向映射（从 dq 到各相功率偏差）：**

反代回可得三相功率偏差与负序 dq 电流的完整矩阵关系：

$$
\begin{bmatrix}\Delta P_a \\ \Delta P_b \\ \Delta P_c\end{bmatrix}
= \frac{V}{2}
\underbrace{\begin{bmatrix}1 & 0 \\ -\dfrac{1}{2} & -\dfrac{\sqrt{3}}{2} \\[4pt] -\dfrac{1}{2} & \dfrac{\sqrt{3}}{2}\end{bmatrix}}_{\displaystyle\mathbf{M}}
\begin{bmatrix}i_{d-} \\ i_{q-}\end{bmatrix}
$$

矩阵 $\mathbf{M}$ 实质上是幅值不变 Clarke 逆变换的前两列转置，结构完全对称。$i_{d-}$ 决定 A 相与 BC 两相之间的功率分配，$i_{q-}$ 决定 B、C 两相之间的功率分配。

> **结论：对于三线制（无中线）系统，正序 + 负序共 4 个控制自由度，映射到控制变量为 $\{i_{d+}^*, i_{q+}^*, i_{d-}^*, i_{q-}^*\}$，恰好对应 $\{P_a^*, P_b^*, P_c^*, Q_{total}^*\}$ 四个控制目标——三相各相有功功率可独立控制，同时保留对总无功功率的控制能力。**

#### 5.3.3 能否同时控制逐相无功功率？

**答案：三线制下不能；四线制（含中线）下可以。** 以下给出严格推导。

**Step A — 推导各相无功与负序 dq 的关系**

对相同的平衡正序电压，结合负序电流 $i_a^- = I^-\cos(\omega t - \phi^-)$，计算各相平均无功（以电流滞后电压为正方向）：

$$
\Delta Q_a = \frac{V}{2}\,i_{q-}, \quad
\Delta Q_b = \frac{V}{2}\!\left(\frac{\sqrt{3}}{2}\,i_{d-} - \frac{1}{2}\,i_{q-}\right), \quad
\Delta Q_c = \frac{V}{2}\!\left(-\frac{\sqrt{3}}{2}\,i_{d-} - \frac{1}{2}\,i_{q-}\right)
$$

完整的六方程系统（以 $\frac{V}{2}$ 为单位）：

$$
\begin{bmatrix}P_a \\ P_b \\ P_c \\ Q_a \\ Q_b \\ Q_c\end{bmatrix}
=
\frac{V}{2}
\begin{bmatrix}
1 & 0 & 1 & 0 \\
1 & 0 & -\tfrac{1}{2} & -\tfrac{\sqrt{3}}{2} \\
1 & 0 & -\tfrac{1}{2} & \tfrac{\sqrt{3}}{2} \\
0 & 1 & 0 & 1 \\
0 & 1 & \tfrac{\sqrt{3}}{2} & -\tfrac{1}{2} \\
0 & 1 & -\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2}
\end{bmatrix}
\begin{bmatrix}i_{d+} \\ i_{q+} \\ i_{d-} \\ i_{q-}\end{bmatrix}
$$

这是一个 **6 方程 × 4 未知量** 的超定系统。4 个控制变量只能满足 4 个独立目标，无法同时独立控制全部 6 个目标 $\{P_a, P_b, P_c, Q_a, Q_b, Q_c\}$。

**Step B — 三线制的根本耦合：有功与无功分布之间的 90° 旋转约束**

定义功率分布向量的 Clarke 分量（幅值不变约定）：

$$
\Delta P_\alpha = \Delta P_a = \frac{V}{2}i_{d-}, \qquad
\Delta P_\beta = \frac{\Delta P_c - \Delta P_b}{\sqrt{3}} = \frac{V}{2}i_{q-}
$$

$$
\Delta Q_\alpha = \Delta Q_a = \frac{V}{2}i_{q-}, \qquad
\Delta Q_\beta = \frac{\Delta Q_c - \Delta Q_b}{\sqrt{3}} = -\frac{V}{2}i_{d-}
$$

因此：

$$
\boxed{\begin{bmatrix}\Delta Q_\alpha \\ \Delta Q_\beta\end{bmatrix} = \underbrace{\begin{bmatrix}0 & 1 \\ -1 & 0\end{bmatrix}}_{\mathbf{R}(-90°)} \begin{bmatrix}\Delta P_\alpha \\ \Delta P_\beta\end{bmatrix}}
$$

> **这意味着：在三线制系统中，无论如何设定负序 dq 电流，各相无功功率的不均衡分布向量在 αβ 空间中永远是有功功率不均衡分布向量顺时针旋转 90° 的结果——两者被同一组 $(i_{d-},\,i_{q-})$ 锁定，无法独立设置。**

实例：若设定 A 相多承担有功（$\Delta P_\alpha > 0$），则 B 相与 C 相之间必然产生一个固定大小的无功差异（$\Delta Q_\beta \ne 0$），无法消除，除非同时放弃有功的不均衡控制。

**Step C — 四线制解锁：零序电流提供额外自由度**

四线制拓扑允许零序电流 $i_a^0 = i_b^0 = i_c^0 = I_0\cos(\omega t - \phi_0)$ 流通。零序参数对各相功率的贡献：

$$
\Delta P_a^0 = \frac{V}{2}i_{d0}, \quad
\Delta P_b^0 = \frac{V}{2}\!\left(-\tfrac{1}{2}i_{d0}+\tfrac{\sqrt{3}}{2}i_{q0}\right), \quad
\Delta P_c^0 = \frac{V}{2}\!\left(-\tfrac{1}{2}i_{d0}-\tfrac{\sqrt{3}}{2}i_{q0}\right)
$$

$$
\Delta Q_a^0 = \frac{V}{2}i_{q0}, \quad
\Delta Q_b^0 = \frac{V}{2}\!\left(-\tfrac{\sqrt{3}}{2}i_{d0}-\tfrac{1}{2}i_{q0}\right), \quad
\Delta Q_c^0 = \frac{V}{2}\!\left(\tfrac{\sqrt{3}}{2}i_{d0}-\tfrac{1}{2}i_{q0}\right)
$$

注意零序电流的有功和无功分布 Clarke 分量：$\Delta P_\alpha^0 = \frac{V}{2}i_{d0}$，$\Delta P_\beta^0 = -\frac{V}{2}i_{q0}$，它的旋转方向与负序**相反（+90°）**，从而两者联合提供了在 αβ 平面中**完整的二维分布控制**。

四线制下完整的分布控制方程（4 目标 × 4 未知量，可验证矩阵行列式 $= -2\sqrt{3} \neq 0$，满秩可解）：

$$
\begin{bmatrix}\Delta P_a \\ \Delta P_b \\ \Delta Q_a \\ \Delta Q_b\end{bmatrix}
=
\frac{V}{2}
\underbrace{\begin{bmatrix}
1 & 0 & 1 & 0 \\
-\tfrac{1}{2} & -\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2} & \tfrac{\sqrt{3}}{2} \\
0 & 1 & 0 & 1 \\
\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2} & -\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2}
\end{bmatrix}}_{\text{满秩，可求逆}}
\begin{bmatrix}i_{d-} \\ i_{q-} \\ i_{d0} \\ i_{q0}\end{bmatrix}
$$

**三线制 vs 四线制控制能力总结：**

| 分析维度                                                                                                        | 三线制（正+负序，4 dof）                                      | 四线制（正+负+零序，6 dof） |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | --------------------------- |
| 总有功$P_{total}$                       | ✅$i_{d+}$ 独立控制              | ✅$i_{d+}$ 独立控制          |                                                               |                             |
| 总无功$Q_{total}$                       | ✅$i_{q+}$ 独立控制              | ✅$i_{q+}$ 独立控制          |                                                               |                             |
| 各相有功分布$\{\Delta P_a,\Delta P_b\}$ | ✅$(i_{d-},i_{q-})$ 控制         | ✅$(i_{d-},i_{q-})$ 控制     |                                                               |                             |
| 各相无功分布$\{\Delta Q_a,\Delta Q_b\}$ | ❌ 被有功分布锁定（R(-90°) 耦合） | ✅$(i_{d0},i_{q0})$ 补偿解耦 |                                                               |                             |
| 零序电流路径                                                                                                    | ❌ 物理上不存在                                               | ✅ 需四桥臂或三单相拓扑     |
| 控制变量数目                                                                                                    | 4：$i_{d+},i_{q+},i_{d-},i_{q-}$ | 6：再加$i_{d0},i_{q0}$ |                             |

#### 5.3.6 实际工程约束（关键局限）

尽管数学上可行，实际应用时有以下重要约束需要评估：

| 约束                                     | 说明                                                                                                                                            | 对策                                               |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **电网标准限制负序电流**           | IEC 61000、IEEE 1547 等标准限制逆变器注入的负序电流幅值（通常$I^-/I_n \leq 10\%$）                                                            | 设计时评估最大功率不平衡度是否超标                 |
| **负序电流幅值随不平衡度线性增大** | 不平衡越大，所需$I^-$ 越大，可能导致过流保护                                       | 需设置不平衡度上限$\|\Delta P\| / P_{total} \leq$ 阈值 |                                                    |
| **负序控制环引入额外延迟**         | DSOGI 提取负序有约 1/4 周期（5 ms@50Hz）的处理延迟，影响动态响应                                                                                | 采用预测控制或减小正负序分离滤波器带宽             |
| **各相瞬时功率仍有脉动**           | 我们控制的是**平均**有功功率，瞬时功率仍含2ω振荡                                                                                         | 若需控制瞬时功率，需更高维度控制（如模型预测控制） |
| **算法复杂度上升**                 | 增加了"功率→序分量转换"和负序控制环，与三个单相方案复杂度趋同                                                                                  | 三相DQ的资源优势部分被侵蚀                         |

> **综合结论：通过在三相DQ框架内叠加负序电流控制，可以实现对各相平均有功功率的独立控制，但代价是引入电流不平衡（受电网标准约束），且算法复杂度向三单相方案靠拢，在此场景下两种方案的资源差距明显缩小。如果应用本身就需要逐相功率控制，三个独立单相方案在工程实现上更自然、逻辑更清晰。**

#### 5.3.7 完整算法：由各相功率参考值计算四路 dq 电流参考值

本节将 5.3.1～5.3.3 的推导汇总为可直接工程实现的完整算法，输入为各相有功/无功参考值，输出为正负序四路 dq 电流参考值。

**功率–电流映射矩阵（6×4）**

设 PLL 已锁定正序电压，相电压峰值为 $V$。对正序与负序电流分别施加对应方向的 Park 变换后，各相平均有功/无功与 dq 电流的完整映射为：

$$
\begin{bmatrix}P_a \\ P_b \\ P_c \\ Q_a \\ Q_b \\ Q_c\end{bmatrix}
=
\frac{V}{2}
\begin{bmatrix}
1 & 0 & 1 & 0 \\
1 & 0 & -\tfrac{1}{2} & -\tfrac{\sqrt{3}}{2} \\
1 & 0 & -\tfrac{1}{2} & +\tfrac{\sqrt{3}}{2} \\
0 & 1 & 0 & 1 \\
0 & 1 & +\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2} \\
0 & 1 & -\tfrac{\sqrt{3}}{2} & -\tfrac{1}{2}
\end{bmatrix}
\begin{bmatrix}i_{d+} \\ i_{q+} \\ i_{d-} \\ i_{q-}\end{bmatrix}
$$

矩阵结构说明：前两列（正序）对每相功率的贡献完全相同（均等分配）；后两列（负序）对每相功率的贡献旋转对称（差额重分配）。

**自由度说明（三线制，4 DOF）**

上述是 **6 方程 × 4 未知量** 的超定系统，三线制物理约束（$i_a+i_b+i_c=0$）使得独立可控目标仅有 4 个：

| 控制变量                                             | 对应物理量                            |
| ---------------------------------------------------- | ------------------------------------- |
| $i_{d+}^*$ | 总有功$P_{total} = P_a + P_b + P_c$ |                                       |
| $i_{q+}^*$ | 总无功$Q_{total} = Q_a + Q_b + Q_c$ |                                       |
| $i_{d-}^*$                                         | 各相有功不均衡分布（A 相 vs BC 平均） |
| $i_{q-}^*$                                         | 各相有功不均衡分布（B 相 vs C 相）    |

**Step 1：正序分量（由总功率直接计算）**

三相相加消去负序项（三列负序之和恒为零）：

$$
\boxed{i_{d+}^* = \frac{2\left(P_a^* + P_b^* + P_c^*\right)}{3V}}
$$

$$
\boxed{i_{q+}^* = \frac{2\left(Q_a^* + Q_b^* + Q_c^*\right)}{3V}}
$$

**Step 2：计算有功偏差**

正序已向每相均等贡献 $P_{total}^*/3$，定义各相需由负序补偿的偏差：

$$
\Delta P_a = P_a^* - \frac{P_{total}^*}{3}, \quad \Delta P_b = P_b^* - \frac{P_{total}^*}{3}, \quad \Delta P_c = P_c^* - \frac{P_{total}^*}{3}
$$

三值之和恒为零，仅两个独立（$\Delta P_c$ 可由 $\Delta P_c = -\Delta P_a - \Delta P_b$ 得出，无需单独计算）。

**Step 3：负序分量（由有功偏差投影计算）**

对映射矩阵有功行取伪逆（$\mathbf{M}^T\mathbf{M} = \tfrac{3}{2}\mathbf{I}$，利用 $\Delta P_b + \Delta P_c = -\Delta P_a$ 化简）：

$$
\boxed{i_{d-}^* = \frac{2\,\Delta P_a^*}{V}}
$$

$$
\boxed{i_{q-}^* = \frac{2\left(\Delta P_c^* - \Delta P_b^*\right)}{\sqrt{3}\,V}}
$$

其中 $V$ 为正序相电压**峰值**；若使用有效值 $V_{rms}$，则将系数 $2$ 替换为 $\sqrt{2}$。

**完整算法伪代码**

```
输入：Pa*, Pb*, Pc*, Qa*, Qb*, Qc*，正序相电压峰值 V

// Step 1：正序
P_total = Pa* + Pb* + Pc*
Q_total = Qa* + Qb* + Qc*
i_dp* = 2 * P_total / (3 * V)
i_qp* = 2 * Q_total / (3 * V)

// Step 2：有功偏差
dPa = Pa* - P_total / 3
dPb = Pb* - P_total / 3
dPc = -dPa - dPb              // 三线制约束，无需单独计算

// Step 3：负序
i_dn* = 2 * dPa / V
i_qn* = 2 * (dPc - dPb) / (sqrt(3) * V)

输出：i_dp*, i_qp*, i_dn*, i_qn*  → 分别送入正/负序 dq PI 控制环
```

**各相无功参考冲突时的处理策略**

当用户同时指定逐相有功和逐相无功（6 个目标），而三线制仅有 4 个控制变量时，可根据优先级选择：

| 策略                           | $i_{d-}^*$、$i_{q-}^*$ 来源                                                                            | 精确满足                                  | 近似满足               |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------- | ---------------------- |
| **优先逐相有功**（推荐） | 由$\Delta P$ 计算（上述方法）                                                                            | $P_a,P_b,P_c$                           | $Q_a,Q_b,Q_c$ 受耦合 |
| **优先逐相无功**         | $i_{d-}^* = -\dfrac{2(\Delta Q_c^* - \Delta Q_b^*)}{\sqrt{3}V}$，$i_{q-}^* = \dfrac{2\Delta Q_a^*}{V}$ | $Q_a,Q_b,Q_c$                           | $P_a,P_b,P_c$ 受耦合 |
| **加权最小二乘**         | $\min\|\mathbf{A}\mathbf{x} - \mathbf{b}\|_W^2$，权矩阵 $W$ 体现优先级                                 | 两者均近似满足                            | —                     |
| **四线制（含零序）**     | 再加$i_{d0}^*$、$i_{q0}^*$ 两个自由度                                                                  | $P_a,P_b,P_c$ | 同时精确$Q_a,Q_b,Q_c$ |                        |

#### 5.3.8 四线制完整算法：逐相有功与无功同时精确控制

**物理基础**

5.3.3 节证明了三线制的根本限制：负序电流的功率分布向量在 αβ 空间中有功与无功分量互为 $\mathbf{R}(-90°)$ 锁定，无法独立设置。四线制引入零序电流后，零序的功率分布向量恰好对应 $\mathbf{R}(+90°)$ 旋转，与负序**方向相反**，两者联合提供了 αβ 平面中完整的二维分布控制能力，从而解除耦合。

**扩展控制结构（6 DOF）**

| 序分量 | 控制变量                                                               | 决定的物理量                        |
| ------ | ---------------------------------------------------------------------- | ----------------------------------- |
| 正序   | $i_{d+}^*$、$i_{q+}^*$ | 总有功$P_{total}$、总无功 $Q_{total}$ |                                     |
| 负序   | $i_{d-}^*$、$i_{q-}^*$                                             | P 分布与 Q 分布（与零序联合解耦）   |
| 零序   | $i_{d0}^*$、$i_{q0}^*$                                             | P 分布与 Q 分布的正交补偿（解耦项） |

6 个控制变量恰好覆盖 6 个独立目标 $\{P_a^*, P_b^*, P_c^*, Q_a^*, Q_b^*, Q_c^*\}$。

**关键方程组（αβ 空间联立，4 方程 × 4 未知量）**

将负序与零序的 αβ 功率分布分量合并，得到以下线性方程组：

$$
\underbrace{i_{d-} + i_{d0}}_{\Delta P_\alpha \text{ 合力}} = \frac{2\Delta P_a}{V} \tag{1}
$$

$$
\underbrace{i_{q-} - i_{q0}}_{\Delta P_\beta \text{ 合力}} = \frac{2(\Delta P_c - \Delta P_b)}{\sqrt{3}\,V} \tag{2}
$$

$$
\underbrace{i_{q-} + i_{q0}}_{\Delta Q_\alpha \text{ 合力}} = \frac{2\Delta Q_a}{V} \tag{3}
$$

$$
\underbrace{-i_{d-} + i_{d0}}_{\Delta Q_\beta \text{ 合力}} = \frac{2(\Delta Q_c - \Delta Q_b)}{\sqrt{3}\,V} \tag{4}
$$

方程 (1)(4) 来自 $\Delta P_\alpha$、$\Delta Q_\beta$ 约束（d 轴方向）；方程 (2)(3) 来自 $\Delta P_\beta$、$\Delta Q_\alpha$ 约束（q 轴方向）。

**闭合解（两组方程各自相加/相减消元）**

由 $(1)+(4)$、$(1)-(4)$ 解 $i_{d-}^*$、$i_{d0}^*$：

$$
\boxed{i_{d-}^* = \frac{\Delta P_a^*}{V} - \frac{\Delta Q_c^* - \Delta Q_b^*}{\sqrt{3}\,V}}
$$

$$
\boxed{i_{d0}^* = \frac{\Delta P_a^*}{V} + \frac{\Delta Q_c^* - \Delta Q_b^*}{\sqrt{3}\,V}}
$$

由 $(2)+(3)$、$(3)-(2)$ 解 $i_{q-}^*$、$i_{q0}^*$：

$$
\boxed{i_{q-}^* = \frac{\Delta Q_a^*}{V} + \frac{\Delta P_c^* - \Delta P_b^*}{\sqrt{3}\,V}}
$$

$$
\boxed{i_{q0}^* = \frac{\Delta Q_a^*}{V} - \frac{\Delta P_c^* - \Delta P_b^*}{\sqrt{3}\,V}}
$$

其中 $V$ 为正序相电压峰值。偏差定义：

$$
\Delta P_k^* = P_k^* - \frac{P_{total}^*}{3}, \quad \Delta Q_k^* = Q_k^* - \frac{Q_{total}^*}{3}, \quad k \in \{a,b,c\}
$$

**完整算法伪代码（四线制，6 个控制变量）**

```
输入：Pa*, Pb*, Pc*, Qa*, Qb*, Qc*，正序相电压峰值 V

// Step 1：正序（与三线制相同）
P_total = Pa* + Pb* + Pc*
Q_total = Qa* + Qb* + Qc*
i_dp* = 2 * P_total / (3 * V)
i_qp* = 2 * Q_total / (3 * V)

// Step 2：有功/无功偏差
dPa = Pa* - P_total / 3
dPb = Pb* - P_total / 3
dPc = -dPa - dPb            // 三值之和恒为零

dQa = Qa* - Q_total / 3
dQb = Qb* - Q_total / 3
dQc = -dQa - dQb

// Step 3：负序与零序（联立方程闭合解）
i_dn* = dPa / V       - (dQc - dQb) / (sqrt(3) * V)
i_qn* = dQa / V       + (dPc - dPb) / (sqrt(3) * V)
i_d0* = dPa / V       + (dQc - dQb) / (sqrt(3) * V)
i_q0* = dQa / V       - (dPc - dPb) / (sqrt(3) * V)

输出：i_dp*, i_qp*, i_dn*, i_qn*, i_d0*, i_q0*
      → 三路 dq PI 控制环 + 矢量叠加（含零序调制）
```

**四路分布参考值的物理对称性**

$$
\underbrace{\begin{bmatrix}i_{d-}^* \\ i_{d0}^*\end{bmatrix}}_{\text{d 轴对}} = \underbrace{\frac{1}{V}\begin{bmatrix}1 & -1/\sqrt{3} \\ 1 & +1/\sqrt{3}\end{bmatrix}}_{\mathbf{T}_d} \begin{bmatrix}\Delta P_a^* \\ \Delta Q_c^* - \Delta Q_b^*\end{bmatrix}
$$

$$
\underbrace{\begin{bmatrix}i_{q-}^* \\ i_{q0}^*\end{bmatrix}}_{\text{q 轴对}} = \underbrace{\frac{1}{V}\begin{bmatrix}1 & +1/\sqrt{3} \\ 1 & -1/\sqrt{3}\end{bmatrix}}_{\mathbf{T}_q} \begin{bmatrix}\Delta Q_a^* \\ \Delta P_c^* - \Delta P_b^*\end{bmatrix}
$$

可见：负序与零序是在 A 相偏差（d 轴行）和 BC 差值（偏差行）之间按 $\pm 1/\sqrt{3}$ 幅度交叉叠加的，两者互为镜像变换。

**与三线制公式的差异说明**

三线制（强制 $i_{d0}^* = i_{q0}^* = 0$）是四线制的特例。施加 $i_{d0}^* = 0$ 约束，由方程 (1)(4) 得：

$$
i_{d-}^*\big|_{\text{3-wire}} = \frac{2\Delta P_a^*}{V}
$$

而四线制的 $i_{d-}^* = \Delta P_a^*/V$（减半）。差异原因：三线制将全部有功重分配压缩于负序，四线制由负序和零序各承担一半。两者在 $\Delta Q = 0$ 时产生相同的各相有功结果，但路径不同。

> **三线制 → 四线制升级时**，切换点必须同步清零 $i_{d0}^*$ 和 $i_{q0}^*$，并将 $i_{d-}^*$ 参考值从 $2\Delta P_a/V$ 切换至 $\Delta P_a/V$，避免阶跃扰动。

**零序 dq 控制的工程实现**

零序电流 $i_0 = (i_a + i_b + i_c)/3$ 在四线制（中线路径存在）下可直接测量。其基波分量与正序参考角 $\theta = \omega t$ 同频，采用单相解调方式提取 dq 分量并送入 PI 控制环：

```
// 一. 提取零序
i0_meas = (i_a + i_b + i_c) / 3

// 二. 单相同步解调（对 i0 在 θ 处做 Park 变换）
i_d0_meas = LPF(2 * i0_meas * cos(θ))   // 低通滤除 2ω 纹波
i_q0_meas = LPF(2 * i0_meas * sin(θ))

// 三. PI 控制
v_d0 = PI(i_d0* - i_d0_meas)
v_q0 = PI(i_q0* - i_q0_meas)

// 四. 零序调制电压（等量叠加到三相调制波）
v_zero(t) = v_d0 * cos(θ) + v_q0 * sin(θ)
v_a_mod += v_zero;  v_b_mod += v_zero;  v_c_mod += v_zero
```

> **拓扑要求**：零序电流通路需要硬件支持——**四桥臂拓扑**（第四路桥臂接中线，可独立控制 $v_{zero}$）或**三个独立全桥**（三单相结构）。传统三相三桥臂拓扑无零序路径，四线制算法不可用。

**四线制六变量算法汇总表**

| 步骤 | 控制变量     | 计算公式                                                                       |
| ---- | ------------ | ------------------------------------------------------------------------------ |
| 1    | $i_{d+}^*$ | $\dfrac{2(P_a^*+P_b^*+P_c^*)}{3V}$                                           |
| 1    | $i_{q+}^*$ | $\dfrac{2(Q_a^*+Q_b^*+Q_c^*)}{3V}$                                           |
| 3    | $i_{d-}^*$ | $\dfrac{\Delta P_a^*}{V} - \dfrac{\Delta Q_c^* - \Delta Q_b^*}{\sqrt{3}\,V}$ |
| 3    | $i_{q-}^*$ | $\dfrac{\Delta Q_a^*}{V} + \dfrac{\Delta P_c^* - \Delta P_b^*}{\sqrt{3}\,V}$ |
| 3    | $i_{d0}^*$ | $\dfrac{\Delta P_a^*}{V} + \dfrac{\Delta Q_c^* - \Delta Q_b^*}{\sqrt{3}\,V}$ |
| 3    | $i_{q0}^*$ | $\dfrac{\Delta Q_a^*}{V} - \dfrac{\Delta P_c^* - \Delta P_b^*}{\sqrt{3}\,V}$ |

### 5.4 三个独立单相方案

每相独立设定有功/无功参考值，天然支持**逐相功率精确控制**：

- A 相注入 3 kW、B 相注入 2 kW、C 相注入 4 kW —— 完全可行
- 可独立补偿各相不平衡负荷
- 适用于需要向不对称负载精确供电的离网场景

**代价：** 三相电流的不对称本身会引入零序/负序，若电网为四线制（含中线）则可实现；若为三线制（无中线），总电流 $i_a + i_b + i_c = 0$ 的约束导致三相控制目标不完全独立，需要额外的约束处理逻辑。

## 6. 不平衡电网适应性

### 6.1 电压不平衡度定义

$$
\text{VUF} = \frac{|V^-|}{|V^+|} \times 100\%
$$

GB/T 15543 要求公共连接点负序电压不平衡度 ≤ 2%（特殊情况 ≤ 4%）。

### 6.2 两方案在不同不平衡度下的表现

| 不平衡度                    | 三相 DQ 方案                       | 三个独立单相方案                      |
| --------------------------- | ---------------------------------- | ------------------------------------- |
| 0%（理想平衡）              | 优秀，控制简单                     | 良好，三路独立稳定运行                |
| 1%～4%（轻度不平衡）        | 需引入负序控制环，有一定复杂度     | 各相自适应，处理自然                  |
| 4%～10%（中度不平衡）       | 必须启用完整正负序分离，调参难度大 | 依然可独立控制，鲁棒性好              |
| >10%（严重不平衡/单相故障） | 控制性能下降，正序提取精度降低     | 故障相可单独限流/退出，其他相继续运行 |
| 单相电压跌落                | 影响全局 PLL，需特殊处理           | 仅该相 PLL 受扰，其余两相不受影响     |

> **结论：三个独立单相方案在不平衡电网下具有天然优势，无需专门的序分量提取算法。**

## 7. 谐波抑制能力

### 7.1 三相 DQ 方案

- 基波正序谐波（1次）：PI 控制无静差
- **特征次谐波**（5、7、11、13 次 = 6k±1 次）：在 dq 坐标系中表现为 6 次、12 次波动，需增加**谐波 dq 旋转坐标系**或**多频率 PR 附加项**抑制
- 负序谐波（5、11 次负序）：需额外负序谐波控制环
- 实现高次谐波抑制时，控制环路数量线性增加，资源优势逐渐消失

### 7.2 三个独立单相方案

- PR 控制器可方便地叠加多个谐振项：$C(s) = K_p + \sum_h \frac{2K_{ih}\omega_c s}{s^2 + 2\omega_c s + (h\omega_0)^2}$
- 每个谐振项独立对应一次谐波，无正负序区分问题
- 各相独立调谐，可针对每相的不同谐波特性单独配置
- 重复控制可作为通用高次谐波补偿模块叠加

> **结论：谐波抑制方面三个独立单相方案更灵活，尤其在各相谐波特征不一致时优势明显。**

## 8. 动态响应特性

### 8.1 阶跃响应

| 指标             | 三相 DQ 方案                         | 三个独立单相方案                |
| ---------------- | ------------------------------------ | ------------------------------- |
| 有功阶跃响应带宽 | 高（dq 域 PI，典型带宽 200～500 Hz） | 中等（PR 控制，受谐振带宽限制） |
| 无功阶跃响应     | 高                                   | 中等                            |
| 相间耦合扰动     | 低（Park 变换后解耦）                | 无（完全解耦）                  |
| 不对称扰动响应   | 需负序控制环介入，有一定延迟         | 各相独立响应，无额外延迟        |

### 8.2 暂态过程中的差异

三相 DQ 方案的 Park 变换假设三相对称，暂态不对称期间（如单相故障起始）会在 dq 轴产生双频扰动，需要陷波滤波器或 DDSRF 联络，增加了暂态响应时间（典型额外延迟 5～20 ms）。

三个独立单相方案无此问题，各相独立完成暂态过渡，互不影响。

---

## 9. 故障穿越能力

### 9.1 低电压穿越（LVRT）

**三相 DQ 方案：**

- 电压对称跌落：正序分量直接下降，正序 PLL 锁相稳定，控制切换至无功优先模式，响应快
- 电压不对称跌落（单相/两相）：负序分量突增，PLL 受扰，正序提取延迟，控制可能短时振荡
- 需预先设计负序电流限幅，防止过流

**三个独立单相方案：**

- 各相独立检测跌落，独立切换至 LVRT 模式
- 未跌落相不受干扰，可持续正常控制
- 无正序提取延迟问题，响应更快
- 各相可独立注入无功，灵活支撑各相电压

### 9.2 孤岛检测

- 三相 DQ 方案：通常基于频率偏移或功率扰动，全局一个检测逻辑
- 三个独立单相方案：每相可独立检测，也可三相协同，但需避免三路检测信号相互干扰导致误判

## 10. 实现复杂度与调试难度

### 10.1 算法实现

| 阶段     | 三相 DQ 方案                                           | 三个独立单相方案                             |
| -------- | ------------------------------------------------------ | -------------------------------------------- |
| 理论建模 | 需掌握 Clarke/Park 变换、正负序理论、矢量功率理论      | 需掌握 PR 控制器、SOGI 原理，理论门槛较低    |
| 代码实现 | 变换矩阵、DSOGI、双 PLL 耦合逻辑，代码耦合度高         | 三套相同代码（可用循环或复用函数），结构清晰 |
| 参数整定 | 正负序 PI 参数 + DSOGI 带宽 + PLL 带宽联合调试，耦合强 | 每相独立调参，互不影响，调参周期短           |
| 仿真验证 | 需覆盖平衡/不平衡多种工况，仿真工况多                  | 单相仿真结果可直接指导三相调参               |
| 现场调试 | 全部场景一套逻辑，出问题定位较难                       | 可逐相上电调试，问题相容易隔离               |

### 10.2 典型陷阱与难点

**三相 DQ 方案常见难点：**

1. DSOGI 中心频率自适应跟踪（电网频率偏移时需动态更新）
2. 正负序分离的相位延迟导致控制性能下降
3. 不平衡工况下正序锁相角受负序污染，引起 2 倍频振荡
4. 正负序电流限幅的协调（总电流约束 vs 各分量约束）
5. 坐标系切换时的初始值设置（避免阶跃扰动）

**三个独立单相方案常见难点：**

1. 三相输出的对称性依赖三路 PLL 的一致性，需统一参考时钟
2. 三线制拓扑中零序电流路径不存在，三相独立控制目标需满足 $i_a+i_b+i_c=0$
3. 各相 PR 谐振频率需与实际电网频率精确对齐（电网频率漂移时需自适应）
4. 相间环流控制（多机并联时）

## 13. 选型建议

### 场景决策树

```
是否需要逐相精确控制功率？
├── 是 ─→ 三个独立单相方案
└── 否
     ├── 电网是否经常严重不平衡（VUF > 4%）？
     │    ├── 是 ─→ 三个独立单相方案（或三相DQ+完整正负序）
     │    └── 否
     │         ├── FPGA LUT/DSP 预算是否紧张？
     │         │    ├── 是 ─→ 三相DQ方案
     │         │    └── 否 ─→ 根据团队熟悉度与模块复用需求选择
     └── 是否为模块化单相平台扩展？
          ├── 是 ─→ 三个独立单相方案
          └── 否 ─→ 三相DQ方案
```

### 综合推荐

| 产品定位                               | 推荐方案               | 备注                 |
| -------------------------------------- | ---------------------- | -------------------- |
| 工业级三相储能/光伏逆变器（对称并网）  | **三相DQ**       | 成本低、性能好       |
| 配电侧不平衡治理装置                   | **三个独立单相** | 逐相控制是核心需求   |
| 微电网主从控制（带不平衡负载）         | **三个独立单相** | 离网时需逐相稳压     |
| 中低压 SVG（对称无功补偿）             | **三相DQ**       | 资源省、响应快       |
| 户用储能（单相/三相兼容平台）          | **三个独立单相** | 统一平台降低研发成本 |
| 数据中心 UPS（高可靠性，含不对称负载） | **三个独立单相** | 故障隔离能力强       |

### 混合方案探讨

在资源允许的情况下，可以考虑**混合方案**：

- 平衡工况下运行三相DQ，发挥其动态响应快、资源省的优势
- 检测到不平衡度超过阈值时，切换或叠加独立单相控制策略
- 此方案复杂度最高，适合高端产品

### A. 控制带宽典型值

| 控制环       | 三相DQ方案        | 三个独立单相方案                  |
| ------------ | ----------------- | --------------------------------- |
| 电流内环带宽 | 300～800 Hz（PI） | 100～400 Hz（PR，受谐振带宽限制） |

### B. 正负序分离常用方法

| 方法                      | 计算延迟      | 精度 | 适用场景   |
| ------------------------- | ------------- | ---- | ---------- |
| DSOGI（双二阶广义积分器） | 约 1/4 周期   | 高   | 通用       |
| DDSRF（解耦双同步坐标系） | 约 1/4 周期   | 高   | 高性能场景 |
| 陷波滤波器                | 约 1/2 周期   | 中   | 简单实现   |
| 延迟信号对消法            | 精确 1/4 周期 | 中   | 定频电网   |

### C. PR 控制器典型参数

$$
C_{PR}(s) = K_p + \frac{2K_i \omega_c s}{s^2 + 2\omega_c s + \omega_0^2}
$$

| 参数         | 典型值                   | 说明                       |
| ------------ | ------------------------ | -------------------------- |
| $K_p$      | 5～20                    | 比例增益，影响动态响应     |
| $K_i$      | 100～500                 | 谐振增益，影响稳态精度     |
| $\omega_c$ | 3～15 rad/s              | 谐振带宽，影响频率适应性   |
| $\omega_0$ | $2\pi \times 50$ rad/s | 谐振频率，需与电网频率同步 |
